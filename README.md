# Tank War ULTIMATE 4.0

定位：
单机坦克射击游戏，不是 MOBA。
地图只采用 MOBA 风格的高级俯视战场视觉。

功能：
- 弯曲战场道路
- 草地 / 岩石 / 废墟 / 石墙
- 障碍碰撞
- 玩家坦克 + 自动炮塔瞄准
- 普通 / 快速 / 重型敌军
- 每 5 波 Boss
- Boss 血条
- 炮弹尾迹 / 炮口火焰 / 爆炸粒子 / 震屏
- 敌军残骸
- 维修技能
- 金币、最高波次、永久强化存档
- 手机摇杆方向：手指推哪边，坦克就往哪边
- FIRE 按住连续射击
