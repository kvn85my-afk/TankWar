# TankWar V4.1 - No Assets Folder

这个版本专门为手机解压/上传 GitHub 简化：
所有文件都放在同一层，不需要 assets 文件夹。

应看到 9 个文件：
1. index.html
2. style.css
3. game.js
4. tank_player.svg
5. tank_enemy.svg
6. explosion.svg
7. shoot.wav
8. explosion.wav
9. README.md

玩法：
- 左下虚拟摇杆移动
- 右下 FIRE 开炮
- 自动瞄准最近敌人
- 敌军 AI / 敌军开炮
- 波次、血量、金币
- 大厅升级装甲、火力、射速、引擎
- 浏览器本地自动存档
