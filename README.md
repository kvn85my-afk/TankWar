# Tank War ULTIMATE 6.0 — Visual Remake

本版直接基于你已经能玩的 5.0 升级，保留原本 Wave、摇杆、射击、金币、车库和永久强化。

6.0 重点：
- 更接近俯视角战争手游/MOBA地图质感，但玩法仍然是单机 Wave 坦克射击
- 坦克重画：履带、轮组、装甲板、炮塔、炮管、金属渐变、阴影、高光
- 玩家坦克加入青绿色能量描边与底部光环
- 地图升级：弯曲泥路、草丛、碎石、地面颗粒、废墟阴影、裂纹
- 炮弹发光轨迹、粒子爆炸、震屏、暗角电影效果
- 保留 5.0 localStorage 存档 key，因此原金币/强化继续使用
