# Tank War ULTIMATE 5.0 — Graphics Upgrade

这是单机 Wave 坦克射击游戏，不是 MOBA。
本版保留 4.0 已验证的操作和玩法，重点升级视觉。

升级内容：
- 更立体的程序化坦克：履带、装甲车体、独立炮塔、炮管
- 更丰富的草地与弯曲泥土道路
- 岩石 / 墙体加入阴影、裂纹和层次
- 炮弹发光尾迹、爆炸粒子、炮口效果、震屏
- 敌军残骸
- 普通 / 快速 / 重型敌军 + 每 5 波 Boss
- Boss 血条
- 维修技能
- 永久车库强化
- 手机摇杆保持正确方向
- 不依赖外部图片素材，GitHub Pages 可直接运行
